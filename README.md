# Bucknell LLM
This is a collection of tools and skills for LLMs to interact with the following resources:
- Moodle
- Gradescope
- Gmail
- Google Drive / Docs / Slides / Sheets ...
- Google Calendar
- Linear (Issue tracker - I use this for keeping track of assignments)

## Your Todo:
- Install LM Studio Bionic and preferably grab an 'instruct' model with thinking. I use Qwen3.5-4B
- Create a Linear workspace. Free up to 250 active issues
- Setup a Google app with OAuth scopes etc. Your agent can give better guidance but this is kind of a todo for me
- Sign in to Moodle
- Provide Gradescope cookies
- Create .env.yml with all of your auth / application state
- Ask your agent to "bootstrap" everything. Sync moodle and gcal.

## Limitations:
- Some models are limited / not very good with tools. Create an issue and I will make the tools more usable.
- Create an issue if you have trouble with setup, I'll try to make things easier.
- This is probably optimized for windows machines. If you have a mac and run into issues let me know and I can make things better
- Make an issue! I will be happy to help.
