# Fast Check Vault

Runs PyMarkdown, Flint, vault integrity, negative rule tests, and ls-lint, then returns structured JSON. It does not modify files.

JSON in, JSON out. The default command is `run`. Items the runner will not guess are listed under `needs_llm`.

```powershell
.\tools\fast-check-vault\fast-check-vault.ps1
```
