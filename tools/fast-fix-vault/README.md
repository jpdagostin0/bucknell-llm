# Fast Fix Vault

Applies PyMarkdown autofixes, strips forbidden Linear frontmatter, restores missing class-index links, qualifies unique bare wikilinks, and rechecks.

JSON in, JSON out. The default command is `run`. Items the runner will not guess are listed under `needs_llm`.

```powershell
.\tools\fast-fix-vault\fast-fix-vault.ps1
```
